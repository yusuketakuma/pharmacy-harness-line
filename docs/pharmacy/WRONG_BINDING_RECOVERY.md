# 誤ったLINE紐付けの停止・再登録

目的: 患者情報を誤ったLINE利用者へ紐付けた場合に、旧紐付けを直ちに停止し、正しい利用者のもとで安全に再登録する。

Status: 2026-09-02 local implementation。production適用・実データ操作は未実施。

## 実行条件

- 薬局staffが、薬局所定の方法で申告者と対象患者を確認済みであること。
- 管理画面で正しいLINEアカウントと患者を選択していること。
- 理由は固定値 `wrong_line_binding` とする。氏名、症状、薬歴などを理由欄や監査へ入れない。

## 手順

1. 管理画面の「患者アンケート」で対象患者を開く。
2. 「誤ったLINE紐付けの停止」で注意事項を読み、「この患者のLINE紐付けを停止」を押す。
3. 確認画面で、本人確認済み・対象患者・対象LINEアカウントを再確認して実行する。
4. 「LINE紐付けを停止しました」と表示されたことを確認する。同じ操作の再実行は同じ停止状態へ収束する。
5. 正しいLINE利用者に、薬局のLINEトークから「患者情報・アンケート」を開いてもらい、既存の登録手順で患者情報を新規登録してもらう。
6. 薬局staffは新しい患者情報を確認する。旧患者IDの所有者変更、別患者IDへの自動コピー、旧記録の削除・アーカイブは行わない。

## システム上の結果

- 旧利用者は次のserver requestから対象患者を閲覧・更新できない。
- privacy再同意、通知再開、proxy再登録では停止状態を解除できない。
- 旧記録は法定保存や監査のため残り、薬局staffのaccount-scoped画面からのみ確認できる。
- 監査にはaccount/patient/owner/staff ID、固定理由、control version、時刻だけを記録し、臨床payloadは記録しない。

## 失敗時

- エラー時は画面を再読み込みし、対象アカウントと患者を再確認して1回だけ再実行する。
- 成功表示を確認できない状態で、所有者IDの直接変更、D1の手動更新、旧記録のコピーや削除を行わない。
- 誤って停止した場合も、その場で旧紐付けを復活させない。本人確認をやり直し、正しい利用者から新規登録する。
