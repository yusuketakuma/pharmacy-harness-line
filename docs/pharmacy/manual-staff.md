# 薬局スタッフ向け 1 枚マニュアル（管理画面）

患者が LINE から送った処方せん・アンケート・各種受付を、管理画面で確認・対応する手順です。

## 1. ログインと仮パスワードの変更

1. 管理画面のログインページで「薬局コード」（薬局ごとの 6 桁の番号）、「管理者ID」、「パスワード」を入力し「ログイン」を押します。
2. 初回は「初回パスワードを変更」画面になります。「現在の仮パスワード」と「新しいパスワード」（12 文字以上 128 文字以下）を入力し「パスワードを変更して進む」を押します。
3. パスワードを忘れたら、薬局のオーナーまたは管理者に仮パスワードの再発行を依頼してください。
4. 作業が終わったらサイドバー下の「ログアウト」を押します。

## 2. サイドバーの見方（薬局向け 4 グループ）

| グループ | 画面 | 用途 |
| --- | --- | --- |
| 本日の業務 | 「処方せん受付」「電子処方箋受付」「緊急避妊薬」「薬局の動き」 | 毎日確認する受付キュー |
| 患者対応 | 「患者アンケート」「継続フォロー」 | 患者ごとの回答とフォロー |
| 設定 | 「機能設定」「患者向け薬局情報」「薬局統計」 | 患者に見せる機能・情報の設定 |
| コンプライアンス | 「個人情報の取扱い」「開示・消去請求」 | 個人情報の掲示と請求の記録 |

ダッシュボードの「本日の対応」に各キューの件数が出ます。「対象画面を開く →」で該当画面に移動できます。

## 3. 処方せん受付キュー

1. 「処方せん受付」を開きます。「処方せんの状態」で絞り込み、「患者名または受付番号で絞り込み」で検索できます。
2. 「詳細を見る」で「処方せん詳細」を開き、「画像」で写真を確認します。患者が到着済みなら「来局済み・詳細を見る」と表示されます。
3. 「薬剤師確認」欄で「発行元分類」と「交付日」を入れて「発行元を保存」「使用期限を保存」を押します。使用期限が未確認のままだと受付できません。
4. 「受付回答」欄で「受付可能」「条件付きで受付可能」「一部準備可能」「今回は受付不可」を選び、「準備予定時刻」「受取方法」などを入れて「受付内容を保存」を押します。
5. 状態を進めるボタン（押すと患者に LINE 通知されます）
   - 受付内容の確認待ち → 「確認して受付する」または「再送を依頼」（「再送理由」を選ぶ）
   - 受付済み → 「準備完了にする」または「再送を依頼」
   - 準備完了 → 「受け渡し完了」
   - 下書き・再送依頼中 → 「キャンセル」
6. 患者と個別にやり取りする場合は「個別チャットを開く」を使います。

## 4. 電子処方箋の正式確認

1. 「電子処方箋受付」を開きます。「確認キュー」には患者が外部画面で操作した記録が並びます（「外部受付を開いた」「患者が操作完了を申告」など）。
2. 患者の「手続きを終えた」は申告にすぎません。必ず薬局側で確認し、結果を「電子処方箋を確認した」「同意登録のみ／処方せんなし」「対象処方せんが見つからない」「他薬局へ提出済み」「使用期限外」「紙処方せんへ切替」「患者確認が必要」「手動例外として記録」から選んで記録します。
3. 「薬局固有のMyna受付URL」は「URLを保存する」で登録し、公式画面で動作を確認したら「公式画面で動作確認済みとして記録」を押します。

## 5. 緊急避妊薬キュー

1. 「緊急避妊薬」を開きます。「受付キュー」に患者の仮受付（「未確認・仮受付」）が並びます。「申告詳細を確認」で申告内容を見ます。
2. 「リスクフラグ」（「未成年確認が必要」「直近購入の確認が必要」など）を確認し、「薬剤師確認済みにする」を押します。
3. 来局・対面対応が終わったら「店頭対応完了として記録」を押します。販売実績は紙記録に残します。この操作は販売可否を自動判定するものではありません。
4. 必要に応じて「受付を取消」「期限切れとして記録」を使います。
5. 「受付条件の設定」で「研修修了薬剤師」「対応枠」「在庫数」「同意文書」「相談支援窓口URL」を登録します。条件がそろうまで患者側の受付は開きません。

## 6. 患者アンケート・継続フォロー・服薬後フォロー

- 「患者アンケート」: 患者を選ぶと「回答詳細」（アレルギー、服用中の薬など）と「対応履歴（新しい順）」が見られます。「再提出依頼」で患者に再回答を求められます。
- 「継続フォロー」: 調剤完了後の「次回事前送信のお知らせ」を管理します。「服用日数を手入力」「予定期間を手入力」で時期を決め、「お知らせを取り消す」「一時停止」で止められます。
- 「服薬後フォロー」（患者アンケート画面内のパネル）: 「お渡し済みの処方せん」を選び「送信日時（日本時間）」を入れて「予約する」。回答が来たら「担当する」→「対応済みにする」または「優先確認にする」「完了にする」で進めます。

## 7. 機能設定（ON/OFF）

1. 「機能設定」で患者向け LIFF に表示する機能（「処方せん事前送信」「電子処方箋」「患者アンケート」「継続フォロー」「服薬フォロー」「緊急避妊薬」「薬局情報」「個別チャット」）を切り替え、「設定を保存」を押します。
2. OFF の意味: 新しい受付を停止するだけです。既存データは削除されず、対応中の案件は完了・取消まで操作できます。患者側には「確認のみ」と表示されます。
3. 「設定診断」に「要対応」が出ている項目は、LINE 側の設定が不足しています。
4. 「リッチメニュー候補」は確認用の画像です。確認だけでは LINE の表示は変わりません。リッチメニューの公開は別途、人が行う操作です。

## 8. 患者向け薬局情報と個人情報の掲示

- 「患者向け薬局情報」: 「薬局名」「営業時間」「処方せん受付時間」「休業・臨時案内」「住所」「電話番号」「アクセス案内」などを入力し「保存する」を押します。患者の「薬局情報」画面にそのまま表示されます。
- 「個人情報の取扱い」: 「利用目的」「問い合わせ窓口」「委託関係の説明」を入力し「保存する」を押します。患者のアンケート同意欄に貴薬局の名義で表示されます。
- 「開示・消去請求」: 「対象の患者」と「請求の種類」（「開示請求」「訂正請求」「消去請求」「利用停止請求」）を選び「請求を受け付ける」。その後「本人確認済みにする」→「法定保存を判定」→「対応済みとして記録」または「対応不可として記録」の順で記録します。

## 9. やってはいけないこと

- 患者の氏名・病名・薬名など個人情報を LINE の自動通知文やテンプレートに書かない（通知は中立的な定型文のみ）。
- 患者の「手続きを終えた」「仮受付」を正式な受付・販売確定として扱わない。必ず薬局側で確認して記録する。
- ログイン情報を共有しない。退職者のアカウントは「スタッフ管理」で無効化する。
- 管理画面の画面写しを外部に送らない。

## よくある質問

| 困ったこと | 対処 |
| --- | --- |
| 「LINEアカウントを登録してください。」と出る | サイドバー上部のアカウント切替で薬局の LINE アカウントを選ぶか、「LINEアカウント」で登録します。 |
| 「受付内容の確認が完了していません」と出る | 「受付回答」を保存してから状態を進めてください。 |
| 「処方せんの使用期限を確認してください」と出る | 「薬剤師確認」で「交付日」を入れて「使用期限を保存」してください。 |
| 「状態を更新しました。LINE通知は再試行待ちです。」と出る | 状態は保存済みです。通知は自動で再送されます。患者から連絡があれば口頭で案内してください。 |
| 「別の更新がありました。最新の設定を再取得しました。」と出る | 他のスタッフが同時に保存しました。内容を確認してもう一度保存してください。 |
| 「セッションの有効期限が切れました」と出る | もう一度ログインしてください。 |
| 画面が更新されない | 「再読み込み」を押すか、ブラウザを再読み込みしてください。改善しなければシステム担当に連絡してください。 |
