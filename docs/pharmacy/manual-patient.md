# 患者向け 1 枚マニュアル（LINE で処方せんを送る）

薬局の LINE 公式アカウントから使えるサービスのご案内です。スマートフォンの LINE アプリで操作します。

## 1. 画面を開く

1. 薬局の LINE トーク画面を開きます。
2. 画面の下にあるメニュー（リッチメニュー）を押します。
3. 「すべての機能」の画面が開きます。使いたい機能を押してください。
   - 「今すぐ行う」: 「処方せん事前送信」「電子処方箋」「患者情報・アンケート」「緊急避妊薬」
   - 「送信後の確認・フォロー」: 「受付状況」「継続フォロー」「服薬後フォロー」
   - 「薬局情報・相談」: 「薬局情報」「薬局へ相談」
4. 「確認のみ」と表示された機能は、新しい申し込みはできませんが、いまの状況の確認はできます。

## 2. はじめて使うとき（患者情報・アンケート）

1. 「患者情報・アンケート」を押します。
2. 「本人を登録」を押し、「氏名」「氏名カナ」「生年月日」を入力して「患者を登録する」を押します。ご家族の分は「家族を追加」から登録できます。
3. アンケートは 3 ステップ（「安全確認」「体調・生活」「確認・送信」）です。「必須」の質問に答えて「次へ」を押します。
4. 最後に、回答を薬局へ伝えることと個人情報の利用目的の 2 つにチェックを入れて送信します。
5. 2 回目以降、変わりがなければ「前回から変更なしで更新」を押すだけで済みます。
6. 入力途中で「すべての機能へ戻る」などを押すと、未送信の入力を破棄してよいか確認されます。アンケート回答はこの画面を開いている間だけ保持し、端末の保存領域には残しません。画面を閉じた場合は入力し直してください。

## 3. 処方せんの写真を送る

1. 「処方せん事前送信」を押します。
2. 「患者を選択」で、お薬をもらう人を選びます。
3. 「カメラで撮影・画像を選択」を押して、処方せんを撮影します。
   - 写真は 1 〜 4 枚まで。全体が入り、文字が読める明るい写真にしてください。
   - 撮り直したいときは写真の「削除」を押します。
4. 「希望受取日時（任意）」と「希望する受け取り方法」（「薬局で受け取る」または「配送を希望（薬局の確認後に確定）」）を選びます。
5. 「処方せん原本を持参します」と「準備完了通知をLINEで受け取ります」の 2 つにチェックを入れます。
6. 「送信内容を確認する」を押し、内容を確かめて「この内容で送信する」を押します。
7. 「処方せんを送信しました。薬局からの連絡をお待ちください。」と出れば送信完了です。

**大切なこと**: 送信しただけでは受付完了ではありません。薬局からの確認連絡をお待ちください。来局のときは必ず処方せんの原本をお持ちください。

## 4. 受付状況を見る

1. 「受付状況」を押します。送った処方せんが新しい順に並びます。
2. 状態の見方
   - 「受付内容の確認待ち」: 薬局が内容を確認中です。
   - 「再撮影が必要」: 写真が読めませんでした。「再撮影する」を押して送り直してください。
   - 「受付済み」: 薬局が受け付けました。準備予定の時刻が表示されます。
   - 「お薬の準備完了」: お薬ができました。来局してください。
   - 「受け取り済み」: お渡しが終わりました。
3. 薬局に着いたら「来局しました」を押すと、到着が薬局に伝わります。
4. 確認待ちのうちは「送信を取り消す」で取り消せます。

## 5. 電子処方箋（マイナ保険証）で手続きする

1. 「電子処方箋」を押し、「電子処方箋の手続きを始める」を押します。外部の受付画面が開きます。
2. 手続きが終わったら、この画面に戻って「手続きを終えた」を押します。途中でやめた場合は「紙の処方せんに切り替える」などを選べます。
3. 「手続きを終えた」は、ご自身からの申告です。薬局が確認するまで正式な受付にはなりません。状態は「完了を申告済み（薬局確認待ち）」→「薬局で受領済み」と進みます。

## 6. 継続フォロー・服薬後フォロー

- 「継続フォロー」: 次回の処方せんを送る時期のお知らせです。「お知らせを受け取る」または「今回は登録しません」を選びます。お知らせは薬の確保や調剤を約束するものではありません。
- 「服薬後フォロー」: お薬を使った後の様子を「問題なく使えている」「気になることがある」「薬剤師に相談したい」から 1 つ選んで送ります。送信後は変更できません。強い息苦しさなど緊急のときは、この画面を待たず 119 へ連絡してください。

## 7. 緊急避妊薬の仮受付

1. 「緊急避妊薬」を押し、「説明と明示同意」を読んでチェックを入れます。同意文には「申告内容は来局時に薬剤師が対面で再確認し、最終的な判断は店頭で薬剤師が行います」「申告内容の保存期間はN日間です」「薬剤師が作成する販売記録は法令により3年間保存され、申告内容とは別に扱われます」「服用から3週間後を目安に、検査薬または受診で結果をご確認いただくご案内をお送りします」という内容が含まれます。
2. 「対象となる出来事の日時」を入力すると、その場で「服用期限：〇月〇日 〇時（残り約〇時間）」が表示されます。「希望する対応枠」の一覧では、この期限を過ぎる枠は選択できないようグレーアウトし「（期限超過）」と表示されます。
3. 「あてはまる場合はチェックしてください（送信は止まりません）」の欄で、次の4つのうち当てはまるものにチェックを入れます。
   - 「レボノルゲストレルを含む薬でアレルギー症状が出たことがある」
   - 「肝臓病の診断を受けている」
   - 「現在、お腹に赤ちゃんがいることが分かっている」
   - 「授乳中」
   いずれかにチェックを入れても送信は止まりません。チェックすると「当てはまる項目があるため、以下もあわせてご検討ください」という案内とともに、産婦人科の受診、相談窓口、厚生労働省の販売薬局一覧への案内リンクが表示されます。
4. 「あてはまる場合はチェックしてください（お薬手帳の持参案内に使います）」の欄で、次の4つのうち当てはまるものにチェックを入れます。
   - 「医師の治療を受けている」
   - 「薬でアレルギー症状が出たことがある」
   - 「心臓病・腎臓病・重度の消化器疾患の診断を受けている」
   - 「セイヨウオトギリソウ（セント・ジョーンズ・ワート）を含む食品を摂っている」
   いずれか1つでもチェックすると、送信完了後の案内に「来局時にお薬手帳をお持ちください。」が追加されます。
5. 「直近の月経について」で「直近の月経が始まった日」を入力するか「わからない」にチェックを入れます。続けて「当てはまるものにチェック（複数可）」から次のいずれかを選びます。
   - 「直近の月経開始から1か月以上、次の月経がない」
   - 「出産などのあとで月経が戻っていない」
   - 「直近の月経が、いつもと違った（量が少ない・期間が短いなど）」
   - 「直近の月経のあとで、今回より前に心配な出来事があり、3週間以上たっている」
   - 「当てはまるものはない」
   - 「わからない」
   「当てはまるものはない」「わからない」と具体的な項目は同時に選べません。いずれも選ばずに送信しようとするとエラーになります（未回答のままでは進めません）。この回答は薬剤師のみが確認し、患者の画面には結果（検査推奨の有無）は表示されません。
6. 「本人確認書類を持参できる（任意）」で「はい」「いいえ」「未定」のいずれかを選びます（未入力のままでも送信できます）。
7. 「来局と服用方法の確認」で「本人が薬局へ来局します」「薬剤師の面前で服用します」にチェックを入れます。
8. 「送信内容を確認する」→「この内容で送信する」で仮受付になります。受付番号が表示されるので、来局時にお伝えください。
9. これは仮受付です。販売するかどうかの最終判断は、来局時に店頭の薬剤師が行います。薬剤師が作成する販売記録は法令により3年間保存され、申告内容とは別に扱われます。受付できない場合や送信完了後は、画面の「相談窓口を見る（外部サイト）」「受付できない場合の相談先」から相談窓口の案内を確認できます。

## 8. 薬局情報

「薬局情報」で「営業時間」「処方せん受付時間」「住所・アクセス」などを見られます。「電話する」「Google Mapsで開く」ボタンも使えます。

## よくある質問

| 困ったこと | 対処 |
| --- | --- |
| 画面が真っ白・エラーになる | 画面をいったん閉じ、LINE のトークからメニューを押して開き直してください。「再試行」「再読み込み」ボタンがあれば押してください。 |
| 「この機能は現在利用できません」と出る | この薬局では現在その機能を受け付けていません。「すべての機能へ戻る」を押してください。 |
| 写真が送れない | 写真は JPEG か PNG、1 枚 10MB 以下、4 枚までです。枚数を減らして再度お試しください。 |
| 「患者アンケートに回答してください」と出る | 先に「患者情報・アンケート」で回答してから処方せんを送ってください。 |
| 受付状況が変わらない | 薬局が確認中です。急ぎの場合は「薬局へ相談」を押すか、お電話ください。 |
| 薬局に相談したい | 「すべての機能」の「薬局へ相談」を押すと、トークに相談メッセージが送られます。その後、トークで用件を書いてください。 |
| 処方せんの原本は必要？ | 必要です。写真は事前準備のためで、来局時に原本をお持ちください。 |
